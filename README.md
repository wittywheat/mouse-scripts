# mouse-scripts
Place frequently used functions of Xpedition Layout on the mouse thumb buttons.

把 scripts 放到 \Documents\MyScripts 里
把 UserAccKey.vbs 放到 $SDD_HOME\standard\automation\startup 目录里
在同目录下的 scripts.ini 里加一行 Script#2=UserAccKey.vbs
按下表分配 Acceleration Key，相应地写进 UserAccKey.vbs 里。

Keyin command 不用或很少用的字母，分配给我的script：
A	Smart Utility turn on all layers
B	Toggle Planes
E
G	Highlight selected nets
I	Toggle “Top and Bottom layers”
J
K
L	Toggle “Active Layer Only”
N	Toggle Netlines
Q
S	Toggle Shadow mode
T
V
W
Y
